A production-grade demonstration website representing ScaleNova's **EliteOS Tier** for ultra-luxury real estate developers, private architects, and turnkey construction firms.

## Features
- **Editorial Luxury Design System**: Ivory (`#FBFBF9`), Warm Alabaster (`#F5F3EF`), Champagne Gold (`#C5A059`), and Deep Charcoal (`#18181A`).
- **Interactive Axonometric Depth Canvas**: Continuous subtle architectural motion and isometric projection.
- **13 Complete Content & Operational Pages**:
  - `index.html` (Hero, signature estates preview, portfolio stats)
  - `about.html` (Founders, architectural lineage, artisanal craft)
  - `properties.html` (Signature collection across Bangalore, Hyderabad, Mumbai, Goa)
  - `featured-property.html` (Monograph of The Alabaster Villa at Whitefield)
  - `residential.html` (Multi-generational family compounds & sky penthouses)
  - `commercial.html` (Corporate headquarters & luxury retail ateliers)
  - `construction.html` (Structural engineering, post-tensioned slabs, acoustic isolation)
  - `process.html` (The 7-stage turnkey creation process)
  - `schedule-visit.html` (Private viewing appointment booking form)
  - `request-brochure.html` (Digital monograph and dossier request form)
  - `insights.html` (The Aurelia Journal: architectural essays & quarry notes)
  - `contact.html` (Design ateliers in Bangalore, Hyderabad, and Mumbai)
  - `privacy.html` (Patron confidentiality and non-disclosure governance)
- **Shared Integration Gateway**: Routes directly to Google Apps Script `DEMO-03`, updating Google Sheet `Demo3_RealEstate` and Frappe CRM (`demo.scalenovasys.com`).

## Quick Start
```bash
npm install # optional
npm run dev # runs serve at port 3003
npm test    # runs system validation test
```
